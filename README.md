# Week 12 Lab Basic: Automating Communications (Email & SMS)

This repository contains the laboratory project for automating communication systems using Python.

## Project: `email-sms-automator`

The complete implementation is located in the [`email-sms-automator/`](./email-sms-automator/) directory.

### Quick Start
```bash
cd email-sms-automator
python -m venv venv
# Activate virtual environment:
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
cp .env.example .env  # Configure your credentials
python main.py
```
